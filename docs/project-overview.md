# SentinelAV Project Overview

## Introduction

SentinelAV is a lightweight endpoint security monitoring system designed to detect newly created files, collect forensic metadata, perform risk assessment, and apply configurable security policies.

The project aims to demonstrate fundamental cybersecurity concepts including endpoint monitoring, file analysis, cryptographic hashing, threat classification, quarantine response, and security event logging.

---

## Objectives

The main objectives of SentinelAV are:

- Monitor filesystem activity in real time
- Collect forensic information from newly created files
- Generate SHA256 file fingerprints
- Perform rule-based risk assessment
- Apply configurable security policies
- Quarantine potentially suspicious files
- Maintain security event logs for analysis
